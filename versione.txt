3.76.0
- Rara 16 / Evoker 16: adesso l'app cerca le DIPENDENZE di un plugin DENTRO la sua cartella.
- Serve per il Renderer di Rara (la direzione/cuffia): lui ha bisogno del file "RaraAtmos16LocalLab.dll" accanto a sé. Senza, Windows non lo apriva e l'app lo saltava (passi/direzione spariti). Ora, se il file c'e' accanto, il Renderer parte.
- Se un plugin non si carica, l'avviso ora dice anche il MOTIVO (es. "manca un file che gli serve accanto").
IMPORTANTE: metti il file "RaraAtmos16LocalLab.dll" nella stessa cartella del Rara16Renderer.dll (es. C:\Program Files\VSTPlugins\VSTPlugins\rara16). Se non ce l'hai lì, cercalo sul PC e copialo accanto al Renderer.
